🔄 Synchroniser depuis Google Sheets
Méthode 1 — un onglet par classe : partagez le classeur en « Tous les utilisateurs disposant du lien · Lecteur » (ou publiez-le sur le web), collez son lien sur une ligne, puis une ligne par classe :
CE6-1 | 1979649015 (le nombre = gid dans l’adresse de l’onglet : …#gid=1979649015).
Méthode 2 — Apps Script (tous les onglets en un seul lien) : voir ci-dessous.
📋 Script Google Apps Script (méthode 2)
  1. Dans votre Google Sheet : Extensions → Apps Script, collez le code, changez la clé.
  2. Déployer → Nouveau déploiement → Application Web · Exécuter en tant que : moi · Accès : Tout le monde → Déployer, autorisez.
  3. Copiez l’URL (…/exec) et ajoutez ?k=VOTRE_CLE : collez-la ci-dessous.
const CLE = "CHANGEZ-MOI";
function doGet(e) {
  const out = {};
  if (e.parameter.k === CLE) {
    SpreadsheetApp.getActive().getSheets().forEach(s => out[s.getName()] = s.getDataRange().getDisplayValues());
  }
  return ContentService.createTextOutput(JSON.stringify(out)).setMimeType(ContentService.MimeType.JSON);
}
